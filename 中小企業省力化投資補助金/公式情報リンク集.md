# 中小企業省力化投資補助金 公式情報リンク集

中小企業省力化投資補助金は、人手不足に悩む中小企業等の省力化投資を支援する制度で、現在は **「一般型」** と **「カタログ注文型」** の2類型で運用されています。本ページは、それぞれの公式情報を素早く参照するためのリンク集です。

## カタログ注文型

事務局がカタログに登録した汎用的な省力化製品の中から、事業者が選択して導入する類型。

| 種別 | リンク |
| --- | --- |
| カタログ注文型 トップページ | [中小企業省力化投資補助金（カタログ注文型）](https://shoryokuka.smrj.go.jp/catalog/) |
| 採択・交付決定事業者一覧（PDF） | [採択・交付決定事業者一覧（カタログ注文型）](https://shoryokuka.smrj.go.jp/assets/pdf/grant_adoption_catalog.pdf) |

> カタログ注文型は随時申請を受け付けるスキームのため、採択者一覧は「○月末時点版」として一本のPDFが定期的に更新される運用になっています（同一URL）。
