# 中小企業省力化投資補助金

## 概要
- 目的: 人手不足に悩む中小企業等に対し、省力化（自動化・効率化）に資する製品の導入を支援することで、生産性向上と賃上げを実現する。
- 制度の背景: 中小企業の深刻な人手不足を背景に、IoT・ロボット等の汎用製品をあらかじめカタログに登録し、迅速かつ簡易に導入できる「カタログ注文型」を中心に運用される。
