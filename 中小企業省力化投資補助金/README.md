# 中小企業省力化投資補助金

> 申請支援に従事する中小企業診断士・行政書士・経営コンサルタント等の参照を主目的とした、制度・実務情報の集約ページ。
> 本資料は公開情報をもとに整理したものであり、最終判断は必ず最新の公募要領（[一般型](https://shoryokuka.smrj.go.jp/ippan/download/) ／ [カタログ注文型](https://shoryokuka.smrj.go.jp/catalog/)）で確認すること。
> 関連内部資料: [公式情報リンク集](公式情報リンク集.md) ／ [採択者一覧リンク集](採択者一覧リンク集.md)

## 1. 制度の全体像

人手不足に悩む中小企業等に対し、省力化（自動化・効率化）に資する設備等の導入を支援することで、生産性向上と継続的な賃上げを実現することを目的とした、中小企業庁所管・中小機構実施の補助制度。現在は **「一般型」** と **「カタログ注文型」** の2類型で運用されている。

| 類型 | 趣旨 | 申請方式 | 対象 |
| --- | --- | --- | --- |
| 一般型 | 現場ごとの課題に応じたオーダーメイド／セミオーダーメイドの省力化投資（設備導入・システム構築等）を支援 | 公募回ごとの締切型・電子申請 | カタログ非登録のオーダーメイド設備・システム |
| カタログ注文型 | 事務局があらかじめ登録した汎用的な省力化製品を選定して導入する簡便型 | 随時申請（販売事業者との共同申請） | カタログ登録製品（IoT・ロボット等の汎用製品） |

出典: [中小機構 公式サイト](https://shoryokuka.smrj.go.jp/) ／ [一般型 制度紹介](https://shoryokuka.smrj.go.jp/ippan/about/) ／ [カタログ注文型 制度紹介](https://shoryokuka.smrj.go.jp/catalog/about/) ／ [ミラサポplus（令和7年版ポイント）](https://mirasapo-plus.go.jp/hint/27807/)

## 2. 一般型

### 2.1 対象者

- 中小企業基本法に定める **中小企業者・小規模事業者・特定事業者等**（法人・個人事業主）
- 申請時点で社会保険加入の従業員が在籍していること（不在の場合は不採択）
- 賃上げに関する表明書（指定様式）の提出が必要

出典: [一般型 制度紹介](https://shoryokuka.smrj.go.jp/ippan/about/) ／ [中小企業庁 第6回公募要領プレス](https://www.chusho.meti.go.jp/koukai/hojyokin/kobo/2026/260313001.html)

### 2.2 補助率

| 区分 | 通常 | 大幅賃上げ特例適用時 |
| --- | --- | --- |
| 中小企業 | 1/2 | 2/3 |
| 小規模事業者・再生事業者 | 2/3 | 2/3 |

加えて、最低賃金近傍で雇用する従業員（地域別最低賃金以上〜翌年度改定の地域別最低賃金未満）が **全従業員の30%以上いる月が3ヶ月以上ある事業者** には補助率を 2/3 に引き上げる「最低賃金引き上げ特例」がある。

出典: [Planbase 解説](https://planbase.co.jp/column/371/) ／ [一般型 制度紹介](https://shoryokuka.smrj.go.jp/ippan/about/)

### 2.3 補助上限額（従業員数別）

| 従業員数 | 通常上限 | 大幅賃上げ特例適用時 |
| --- | --- | --- |
| 5人以下 | 750万円 | 1,000万円 |
| 6〜20人 | 1,500万円 | 2,000万円 |
| 21〜50人 | 3,000万円 | 4,000万円 |
| 51〜100人 | 5,000万円 | 6,500万円 |
| 101人以上 | 8,000万円 | 1億円 |

出典: [一般型 制度紹介](https://shoryokuka.smrj.go.jp/ippan/about/) ／ [Planbase 解説](https://planbase.co.jp/column/371/) ／ [animato解説](https://animato-animato.com/2026/03/23/shoryokuka-subsidy-general-2026-6th/)

### 2.4 対象経費

| 区分 | 内容 | 必須／任意 |
| --- | --- | --- |
| 機械装置・システム構築費 | 省力化に資する機械・装置・システムの取得・改良・修繕等 | **必須**（本費目を含まない申請は不可） |
| 技術導入費 | 知的財産権等の導入費用 | 任意 |
| 専門家経費 | 外部専門家への謝金・旅費 | 任意 |
| 運搬費 | 機械装置等の運搬料 | 任意 |
| クラウドサービス利用費 | 補助事業に関係するクラウド使用料（補助事業期間内） | 任意 |
| 外注費 | 加工・設計等の外注 | 任意 |
| 知的財産権等関連経費 | 特許・実用新案等の出願・取得 | 任意 |

> **補助対象外の代表例**: 将来的な対外販売を前提とする設備・システム開発、購入設備を自ら使わず特定第三者に長期賃貸する事業、解雇を主たる手段として労働生産性等を操作する事業、公募要領に沿わない事業。

出典: [補助金ポータル 一般型解説](https://hojyokin-portal.jp/columns/shoryokuka2025_ippangata) ／ [shoryokuka.smrj.go.jp 公募要領（一般型）](https://shoryokuka.smrj.go.jp/ippan/download/)

### 2.5 賃上げ要件

| 種別 | 要件（第5回以降一本化） |
| --- | --- |
| **基本要件**（必達） | 1人当たり給与支給総額の **年平均成長率 +3.5%以上** |
| **大幅賃上げ特例**（補助上限引上げの条件） | ① 給与支給総額 +6.0%以上 かつ ② 事業場内最低賃金 +45円以上（公募回により基準が見直されるため必ず最新公募要領で確認） |

> 旧制度では「総額ベース」等の選択肢があったが、第5回以降は **+3.5%（1人当たり）に一本化** され、より実質的な賃上げが求められる。
> 大幅賃上げ特例の判定基準（金額ベースの「+45円」⇔ 率ベースの「+3.0%」等）は公募回および類型で揺れがあるため、**必ず適用回の公募要領で確定値を確認すること**。

出典: [Planbase 解説](https://planbase.co.jp/column/371/) ／ [佐藤グループ社労士 解説](https://www.sato-group-sr.jp/business_guide/archives/1212) ／ [シェアビジョン 審査ポイント](https://svltd.co.jp/syouryokuka-hojo-col/detail.html?id=2186)

### 2.7 申請フロー（採択前→採択後）

1. **GビズIDプライム取得**（発行に2〜3週間。**最優先で着手**）
2. 公募要領・申請手引き精読、事業計画書作成
3. **応募申請**（電子申請、締切時刻厳守）
4. 採択発表
5. **交付申請**（採択発表日から原則 **2ヶ月以内**、原則 **2者以上の相見積** が必要）
6. 交付決定
7. 補助事業実施（発注・納品・検収・支払）
8. （必要に応じて）中間検査・状況報告
9. **実績報告**（事業実施期間内に提出）
10. **確定検査**（書面・現地検査）→ 補助金額確定
11. 補助金支払
12. **効果報告**（複数年。賃上げ・労働生産性目標の達成状況を報告）

出典: [応募申請・交付申請の流れ（公式）](https://shoryokuka.smrj.go.jp/ippan/flow/) ／ [大型補助金ナビ 必要書類](https://oogata-hojokin.jp/syoryokuka/p1773) ／ [G1-info 必要書類解説](https://g1info.jp/2025/09/25/syoryokuka-document/)

### 2.8 主な必要書類（応募申請）

- 事業計画書（指定様式）
- **賃金引き上げ計画の表明書**（指定様式、交付申請時に従業員代表署名版を提出）
- 決算書類（直近2期分）
- 法人：履歴事項全部証明書／個人：開業届・確定申告書
- 労働者名簿
- ミラサポplus 経営計画策定支援等の関連書類（必要に応じて）
- 加点項目の証憑（経営革新計画認定書、健康経営優良法人認定証 等）

出典: [応募申請の手引き（第4回公募）](https://shoryokuka.smrj.go.jp/assets/pdf/oubo_manual_ippan_04.pdf) ／ [大型補助金ナビ 必要書類](https://oogata-hojokin.jp/syoryokuka/p1773)

### 2.9 加点項目（一般型）

| 加点項目 | 概要 |
| --- | --- |
| 賃上げ加点 | 給与支給総額の **年平均成長率 +4.0%以上** ＋ 事業場内最低賃金を毎年3月時点で当該都道府県最賃 **+40円以上** の水準とする計画 |
| 事業承継・M&A加点 | 直近に事業承継または M&A を実施した事業者 |
| 省力化ナビ加点（新設） | 中小機構が提供する「省力化ナビ」診断ツールを利用した事業者 |
| 健康経営優良法人加点（新設） | 「健康経営優良法人2026」認定取得事業者 |
| 成長加速マッチングサービス加点 | 中小機構の成長加速マッチングサービス登録事業者 |

> 加点項目は公募回により改廃されるため、適用回の公募要領で最終確認のこと。

出典: [ミラサポplus（令和7年版ポイント）](https://mirasapo-plus.go.jp/hint/27807/) ／ [起業の「わからない」を「できる」に](https://sogyotecho.jp/shouryokukahojyokin/)

### 2.10 審査の観点（公募要領記載の4大項目）

1. **補助対象事業としての適格性** — 制度趣旨・要件・対象経費との整合
2. **技術面** — 省力化技術・実施体制の妥当性
3. **計画面** — 事業計画の実現可能性、収支・スケジュール、資金調達計画
4. **政策面** — 地域経済・産業政策への貢献、賃上げ・生産性向上の波及効果

> 単に「3.5%上げる」と記載するだけでは不十分で、**「省力化投資 → 労働生産性向上 → その収益を原資とした賃上げ」という論理連鎖** が記述・数値で裏付けられているかが審査される。

出典: [シェアビジョン 審査ポイント](https://svltd.co.jp/syouryokuka-hojo-col/detail.html?id=2186) ／ [公募要領（一般型）](https://shoryokuka.smrj.go.jp/ippan/download/)

### 2.11 不採択になりやすい典型例

- 書類不備・添付漏れ（事業者名や法人格の誤記、必要書類の欠落）
- 申請時点で社会保険加入の従業員が不在
- 賃上げの裏付けがなく数値だけが先行する事業計画
- 主たる目的が解雇による生産性指標の操作と判断される事業
- 将来的に対外販売を前提とした設備・システム開発
- 設備の自社使用ではなく第三者への長期賃貸を前提とする事業
- 機械装置・システム構築費を含まない申請

出典: [シェアビジョン 不採択分析](https://svltd.co.jp/syouryokuka-hojo-col/detail.html?id=2246) ／ [補助金の広場 注意点](https://hojyokin-hiroba.com/syouryokuka-subsidy-check-points/)

### 2.13 業種別の採択傾向

- **製造業が約40%**（第1〜2回）。生産ラインでの省力化効果が可視化しやすい業種で採択されやすい。
- 食品製造、金属加工、建設、運輸、卸売、飲食での採択事例多数。
- 採択事例（公開情報の例）: 食品製造業が同一生産ライン上の連動設備を更新し生産能力増強。総事業費約66百万円、補助金約27百万円。

## 3. カタログ注文型

### 3.1 制度の特徴

- 事務局があらかじめ登録した **汎用的な省力化製品（IoT・ロボット等）** をカタログから選定して導入。
- **販売事業者との共同申請**。製品検索→販売事業者選定→共同申請の流れ。
- **随時受付方式**（締切型ではない）。採択・交付決定事業者一覧は同一URLのPDFで月次更新。

出典: [カタログ注文型 制度紹介](https://shoryokuka.smrj.go.jp/catalog/about/) ／ [ミラサポplus カタログ注文型](https://mirasapo-plus.go.jp/hint/24088/)

### 3.2 補助率・補助上限額（2026-03-19制度改定後）

| 従業員数 | 通常上限 | 大幅賃上げ特例適用時 |
| --- | --- | --- |
| 5人以下 | 500万円 | 750万円 |
| 6〜20人 | 750万円 | 1,000万円 |
| 21人以上 | 1,000万円 | 1,500万円 |

- 補助率: **1/2**（一律）

出典: [2026-03-19制度改定（公式）](https://shoryokuka.smrj.go.jp/catalog/revision_260319/) ／ [iCOM技研 制度改定解説](https://www.icom-giken.com/blog/tyumongata_kaisei/) ／ [MACC GROUP](https://shinko-gr.com/service/subsidy/%E4%B8%AD%E5%B0%8F%E4%BC%81%E6%A5%AD%E7%9C%81%E5%8A%9B%E5%8C%96%E6%8A%95%E8%B3%87%E8%A3%9C%E5%8A%A9%E9%87%91%E3%82%AB%E3%82%BF%E3%83%AD%E3%82%B0%E6%B3%A8%E6%96%87%E5%9E%8B%E3%81%AE%E5%88%B6%E5%BA%A6/)

### 3.3 賃上げ要件（カタログ注文型）

- **基本要件**: 事業計画期間内に賃上げ計画を策定し表明
- **大幅賃上げ特例**（2026-03-19改定後）:
  - ① 事業場内最低賃金を **3.0%以上** 増加（日銀の「物価安定の目標」+1.0%相当）
  - ② 給与支給総額を **6.0%以上** 増加
  - ①②の **両方** を満たすこと

> 改定前は「事業場内最低賃金 +45円」等の **金額ベース** だったが、**率ベース**（物価動向連動）に見直された点が支援者として要注意。

出典: [iCOM技研 制度改定解説](https://www.icom-giken.com/blog/tyumongata_kaisei/) ／ [2026-03-19改定（公式）](https://shoryokuka.smrj.go.jp/catalog/revision_260319/)

### 3.4 対象製品

- カタログには **製品カテゴリ（自動作業実行／作業効率化 等）** ごとに製品が登録され、各製品に対象業種・対象工程・期待される省力化効果・活用ポイントが整理されている。
- 製品は中小機構の[公式カタログ](https://shoryokuka.smrj.go.jp/catalog/)から検索可能（業種・工程・カテゴリ別）。

出典: [カタログ注文型 制度紹介](https://shoryokuka.smrj.go.jp/catalog/about/) ／ [スマート補助金 カタログ検索](https://www.smart-hojokin.jp/shoryokuka)

### 3.5 申請フロー（カタログ注文型）

1. GビズIDプライム取得
2. カタログから製品選定 → **販売事業者と打合せ**
3. **共同申請**（電子申請）
4. 交付決定
5. 製品導入・検収・支払
6. 実績報告 → 確定検査 → 補助金支払
7. 効果報告

出典: [申請・手続きの流れ（公式）](https://shoryokuka.smrj.go.jp/catalog/flow/)

## 4. 賃上げ未達・要件違反時の補助金返還リスク

### 4.1 返還の基本構造

- **賃上げ要件未達**: 達成率に応じて補助金を返還（「交付額 × 未達割合」が基本）。
- **大幅賃上げ特例適用後の未達**: 通常上限と特例上限の **差額分** を返還。
- **生産性向上目標の未達**: 「補助金額 ÷ 計画年数」で按分返還。

### 4.2 全額返還・収益納付に至り得る重大事由

- 省力化を通じて **人員整理・解雇** を行っていた場合
- **故意に達成見込みのない事業計画** を策定していた場合
- 意図的に **省力化製品を未使用のまま放置** していた場合
- 補助事業者の故意・過失が原因で労働生産性目標が未達となった場合
- 賃上げによる補助上限額の引き上げを適用後、**賃金を引き下げた** 場合
- 本事業の成果により **収益が得られた** と認められる場合（収益納付）

### 4.3 返還免除（責めに帰さない事由）

- 付加価値額が増加しておらず、かつ企業全体として事業計画期間の過半数が **営業利益赤字**
- **天災等** 事業者の責めに帰さない理由

## 5. 申請支援者向けの実務ポイント

### 5.1 着手すぐに行うべき事項

- **GビズIDプライム** の発行手続き（2〜3週間かかる。これが最大のクリティカルパス）
- 直近2期の決算書、労働者名簿、社会保険加入状況の整備
- 補助金事業のクライアント要件（一般型は同時並行不可、過去採択者制限あり）の確認

### 5.2 事業計画書の論理構成（推奨）

1. **現状の人手不足課題**（定量データ：労働時間、業務量、欠員率等）
2. **省力化投資の内容**（カタログ非掲載のオーダーメイド要素を明確化＝一般型）
3. **省力化効果の定量化**（削減工数、対応可能受注量増、生産性指標）
4. **生産性向上から賃上げ原資への落とし込み**（収益増 → 人件費原資 → +3.5%／+4.0%／+6.0%への裏付け）
5. **資金調達計画**（自己資金・借入の根拠）
6. **政策面の貢献**（地域・業界・サプライチェーン）

### 5.3 加点・特例の組み合わせ最適化

- 補助上限を引き上げる「大幅賃上げ特例」と、加点を稼ぐ「賃上げ加点」は **要件水準が異なる**（特例は給与+6%等、加点は+4.0%）。両立する設計が望ましい。
- 「省力化ナビ加点」「健康経営優良法人加点」は事前準備で取得できる加点なので、**スケジュールが許す案件では必ず狙う**。
- 健康経営優良法人は申請窓口期限があるため **前年から逆算** が必要。

### 5.4 採択後の落とし穴

- **相見積（原則2者以上・同一条件）** の取得失敗で交付申請が遅延・差戻されるケース多数。設備ベンダーの段階で2者見積の段取りを組む。
- 交付申請は採択発表から **2ヶ月以内**。発表前から下準備（仕様確定・見積依頼）を進めておく。
- 効果報告は複数年継続。賃上げ達成状況の管理体制を顧問先と合意しておく。

### 5.5 他補助金との比較・組み合わせ

- **ものづくり補助金**（製品開発寄り）／**IT導入補助金**（汎用ITツール）／**事業再構築系**（事業転換）と補助対象が一部競合。**省力化補助金は「人手不足解消」×「賃上げ」のロジックが本筋** であり、新規開発色が強い案件はものづくり補助金が向く。
- 同一設備に対する複数補助金併用は原則不可。事業範囲・経費区分の切り分けで対処。

## 8. メモ・所感（運用上の留意）

- **第5回以降、賃上げ要件が「+3.5%（1人当たり）」に一本化** されたことで、雇用人員の増加を前提とした「総額ベース」の取り回しはできなくなった。賃上げ計画の作り込みが従来以上に重要。
- **カタログ注文型は2026-03-19改定で補助上限が引き上げ** られた一方、要件が率ベースに見直されたため、改定前後で適用される基準が異なる点に注意（既申請案件の取扱は最新告知を要確認）。
- 採択率が高いとはいえ、**書類不備での足切りが一定数存在** するため、応募申請は最低でも提出期限の **3営業日前** にはアップロード完了を目標とする。
- 効果報告は複数年継続するため、**支援契約の範囲（応募〜実績報告までか、効果報告まで含むか）** を顧問先と事前に明確化しておくべき。
